# ReviewFlow 评价诊断 · QMuse 上架清单

> QMuse 为 AI Agent 分发市场（混排免费/付费），适合做「免费 + 付费」双轨验证。

## Agent 卡片
- **名称**：ReviewFlow 评价诊断
- **简介**：把买家评价变成可执行的改进清单。本地运行、自动脱敏、开源可验。
- **能力标签**：电商评价分析 / 聚类 / 回复生成 / 隐私优先

## 双轨策略（QMuse 混排特性）
- **免费版**：离线关键词引擎，限次诊断 → 拉新、攒口碑、收集失败模式（只收统计）。
- **付费版**：本地 LLM 深度诊断（更强归类 + 多标签覆盖 + 批量导出）→ 转化。

## 资料准备
- 封面图：一张「评价 → 五维问题清单」的信息图（用仓库 README 的表结构即可）。
- Demo：5 条合成评价 → 报告截图（脱敏、无真实数据）。
- 链接：开源仓库 reviewflow-quality-kit（建话语权、可复核）。

## 与开源协同
- 在 Agent 详情里挂开源仓库链接：用户可自部署、可复核质量；社区提 Issue 描述「哪类判错」→ 我们迭代基准集 → 反哺 Agent 准确率（只收统计不收内容）。

## 合规备注
- 明确标注「AI 生成建议，需商家核实」「合成/演示数据不冒充真实案例」。
- 不上传用户真实评价到任何服务器（local-first）。
