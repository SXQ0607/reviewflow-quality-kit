# ReviewFlow 评价诊断 · AITOPIA 上架清单

> 分成模式参考：AITOPIA 平台约 70% 分给创作者。下列为提交所需的 Agent 卡片信息。

## 基本信息
- **Agent 名称**：ReviewFlow 评价诊断
- **一句话**：把买家评价一键变成可执行的改进清单
- **分类**：电商工具 / 数据分析 / 客服提效
- **运行环境**：本地（用户自己部署，隐私零外传）

## 能力描述（给平台用户看）
- 粘贴一批店铺评价，30 秒内得到**分类诊断报告**：物流 / 包装 / 质量 / 客服 / 描述 五大类各占多少、典型原话是什么。
- 每类直接给**动作指令**（如「核对承运时效」「增加缓冲」「统一详情页规格」），不是空话。
- 每类给**可直发的买家回复模板**，不承诺赔偿、不推诿。
- 两档引擎：离线关键词版（免费、秒级）、本地 LLM 版（更强归类，需 Ollama + qwen2.5:7b）。

## 差异化卖点
- **真本地、真隐私**：评价不出本机，自动脱敏手机号/邮箱。
- **开源可验**：质量基准集与方法论已开源，报告质量可被第三方复核。
- **只收统计不收内容**：若开启遥测，仅上报「哪类评价判错」的统计，绝不收集你的真实评价。

## 定价建议
- 基础诊断（关键词版）：免费引流
- 深度诊断（LLM 版 / 批量 / 导出）：按次或订阅，平台抽成后创作者约 70%

## 提交备注
- 提供一段 demo 视频：粘贴 5 条合成评价 → 出报告（用仓库里的 quality_baseline.json 做演示数据，不暴露真实客户）。
- 注明「需本地运行 / 自托管」，避免平台误以为要走云端 API。
