# ReviewFlow 评价诊断 · SwarmSeller 上架清单

> 分成模式参考：SwarmSeller 平台约 75% 分给创作者（高于多数市场）。

## 基本信息
- **Agent 名称**：ReviewFlow 评价诊断
- **Slogan**：评价不再只是差评，是改进清单
- **标签**：#电商 #私域 #客服提效 #零代码

## 给买家（卖家）的核心价值
1. **批量诊断**：一次贴 200 条评价，自动聚类成「物流慢 / 包装破 / 质量差 / 客服慢 / 描述不符」五维问题清单。
2. **给动作不给废话**：每条问题直接对应一个可执行动作（谁做、查什么、改什么）。
3. **回复模板即拿即用**：每类配得体回复，可直发买家，规避「承诺赔偿 / 推诿」红线。
4. **隐私优先**：全程本地，数据脱敏，适合介意数据外传的店铺。

## 为什么挂 SwarmSeller
- 分成比例高（~75%），适合作为长期被动收入入口。
- 平台自带 Agent 分发流量，省去自建获客。

## 交付形态
- 形态 A：卖家在自己机器跑（开源核心 + 本地 LLM）。
- 形态 B：轻量 SaaS 封装（后续）——需解决评价上传的隐私顾虑，建议默认本地、可选云端。

## 定价建议
- 免费档：关键词版，限 50 条/次（引流）
- 付费档：LLM 版不限量 + 导出 CSV/报告，订阅制

## 注意事项
- 强调「报告需人工核实后使用，不得冒充真实客户案例」的免责，符合平台合规。
- demo 用合成数据（quality_baseline.json），不碰真实评价。
